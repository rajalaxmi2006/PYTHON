#what is command line & why we used command line?
-we can initialized any variable/object by using:
    .compile time ->x=10
    .user input ->x=int(input("Enter x value"))
    .using command line
-at the time of program execution if we pass any arguments that arguments as called as command line argument.
-we pass command line argument to initialized any variable or object at time program execution.
-in python to works with command line we used argv(argument vector).
-argv present in sys module.
-argv is used to store all arguments in a list format and all argument type must be string type.
-bydefault argv store one argument that is itself program.
